Slinger - local-first API client
https://github.com/perunok/slinger

PRIVACY
-------
Slinger has no account requirement, no telemetry, no analytics and no crash
reporting. Your data stays on this computer.

Slinger only connects to other systems when you ask it to (sending a request,
signing in to a Slinger Cloud server you chose, getting an OAuth token, ...),
with one exception: the UPDATE CHECK. At every start and once a day Slinger
asks api.github.com for the latest release. No data from your workspaces is
sent. Turn it off in Settings > Updates > "Check for new releases
automatically".

Full privacy policy: https://github.com/perunok/slinger/blob/master/PRIVACY.md
Code signing policy: https://github.com/perunok/slinger/blob/master/docs/CODE_SIGNING.md

To uninstall Slinger, use Windows Settings > Apps > Installed apps, or
"Uninstall Slinger" in the installation folder.
